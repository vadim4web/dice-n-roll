# Dice’n’Roll · Domino Poker

Vue 3 / Vite. Шесть верхних барабанов и шесть нижних пар в FIFO-карусели. Игра полностью статическая: [открыть на GitHub Pages](https://vadim4web.github.io/dice-n-roll/).

## Версии

- `node-js` — исходная версия на JavaScript с локальным Node.js-сервером.
- `vue-classic-v2` — сохранённый тег предыдущей Vue-версии с классикой и блицем.
- `vue-js` — текущая версия с барабанами, FIFO, покером и анализом сессий.
- `gh-pages` — готовая статическая сборка.

## Запуск и публикация

Node.js ≥22.12 используется для разработки и сборки; хостингу Node.js не нужен.

```sh
npm ci
npm run dev
npm test
npm run build
npm run verify:build
npm run preview
```

В PowerShell с запретом `.ps1` используйте `npm.cmd`.

```sh
git push origin vue-js
npm run deploy
```

`deploy` собирает проект и публикует `dist/` в `gh-pages`. В Settings → Pages используется Deploy from a branch → gh-pages → /(root). Относительные пути Vite `base: './'` позволяют работать в `/dice-n-roll/` и на других статических хостингах. `.nojekyll` отключает Jekyll. API и серверного кода нет; Google Fonts имеет системный запасной шрифт.

## Как устроена игра

Старт: **50 Roll и 12 дайсов**. Дайсы — внутриигровой ресурс, а не деньги.

- **Roll** меняет все незакреплённые верхние пары и добавляет 6 дайсов. Цена — один Roll.
- **Drop the Dice** стоит 1 дайс: первая незакреплённая нижняя пара уходит, остальные свободные пары сохраняют FIFO-порядок, новая появляется в последней свободной ячейке справа. Закреплённые нижние ячейки стоят на своих местах.
- **Автопоток** включается отдельно: один такой же Drop каждые 5 секунд за 1 дайс. Его можно остановить; в скрытой вкладке, открытом модальном окне и при выборе фиксации он ждёт. Ручной Drop работает и при включённом потоке. Автоматические ходы помечаются в журнале.
- **Фиксация верха:** 1 / 3 Roll за 1 / 3 дайса. **Фиксация низа:** 3 / 6 Drop за 2 / 4 дайса. Срок уменьшается только от действий своего ряда. Освобождение бесплатно, без возврата потраченного.
- **Совпадение:** одинаковые два числа между любыми верхней и нижней парами, в любом порядке. Масть для совпадения не нужна. Цветные линии показывают все связи; несколько нижних совпадений не умножают выплату одной верхней фишки.
- **Покер:** каждая совпавшая верхняя фишка — одна карта с номиналом её верхнего числа и её мастью. Новая совпавшая верхняя фишка приносит 25 очков, плюс один бонус самой сильной комбинации на поле. Уже оплаченное совпадение второй раз не оплачивается; после замены верхней фишки новый экземпляр может принести очки снова.

Поддержаны совпадение, пара, две пары, тройка, стрит, флеш, фулл-хаус, каре, стрит-флеш, роял-стрит, пять одинаковых, полный стрит и шесть одинаковых. «Роял-стрит» — костяная адаптация: 2–3–4–5–6 одной масти; полный стрит — все числа 1–6. Условия и бонусы описаны в интерфейсе и `title`.

Управление: **R / пробел** — Roll, **D** — Drop, клик по фишке — фиксация, Escape — закрыть выбор. Enter / пробел при фокусе на кнопке активируют эту кнопку обычным способом.

## Ardor Index

Игрок выбирает цель и следующее действие. Вероятность `P` рассчитывается точно по текущему полю, фиксациям и уже оплаченным совпадениям. Для выплаты и события вероятности требуется хотя бы одно новое совпадение.

**Ardor = (1 − P) × 100.** Редкой цели соответствует больший индекс. Это сложность выбранной цели, а не психологическая диагностика. Вероятность цели означает наличие указанной комбинации среди совпавших фишек, а не исключительно её старший класс. Например, тройка содержит пару.

Roll использует динамическое программирование по числам и точные формулы по мастям; Drop — полный перебор 36 новых пар. Учтено, что 1:5 и 5:1 дают одну цель совпадения. Тесты сравнивают все 13 целей с полным перебором 20 736 исходов двух свободных барабанов.

## Локальная история

Каждый завершённый ход сохраняется сразу. `visibilitychange`, `pagehide` и `beforeunload` создают контрольные точки и сохраняют анализ. Возврат восстанавливает ту же сессию; кнопка завершения архивирует её окончательно.

Ключи LocalStorage:

| Ключ | Содержимое |
| --- | --- |
| `dnr-domino-session-v3` | Текущее поле, ресурсы, фиксации, выплаты, накопленная статистика и последние 500 событий |
| `dnr-domino-history-v3` | Сводки последних 20 сессий |
| `dnr-domino-logs-v3` | До трёх последних полных сохранённых журналов; при нехватке места старые журналы убираются первыми |
| `dnr-domino-sound-v3` | Настройка звука |
| `dnr-domino-flow-v3` | Включён ли автопоток |

Roll/Drop-события содержат время, точный шанс выбранной цели, Ardor, результат, остатки ресурсов и снимок поля. Сводная статистика учитывает всю сессию даже после обрезки журнала. В анализ входят средняя сложность выбранных целей, доля успешных ходов, Roll/Drop, фиксации, затраты, комбинации и самая длинная серия без выигрыша. Подробные данные можно скачать в JSON. Данные никуда не отправляются; старые ключи классической версии не удаляются.
