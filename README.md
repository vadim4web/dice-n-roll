# Dice’n’Roll · Набей дайсы за сегодня

Vue 3 / Vite, полностью статическая игра: [GitHub Pages](https://vadim4web.github.io/dice-n-roll/).

Шесть верхних барабанов, нижняя FIFO-карусель и **один постоянный кошелёк дайсов**. Ходы и фиксации тратят его, комбинации пополняют. Нет отдельной валюты очков и фиксированных 50 Roll.

## Запуск

Node.js ≥22.12 нужен для разработки и сборки; на хостинге сервер не нужен.

```sh
npm ci
npm run dev
npm test
npm run build
npm run verify:build
npm run preview
```

В PowerShell с запретом `.ps1` используйте `npm.cmd`.

```sh
git push origin vue-js
npm run deploy
```

`deploy` публикует статический `dist/` в `gh-pages`. Settings → Pages: Deploy from a branch → gh-pages → /(root). `base: './'` поддерживает `/dice-n-roll/` и другие статические хостинги. `.nojekyll` отключает Jekyll. Google Fonts имеет системный запасной шрифт.

## Единая экономика

Каждые местные календарные сутки один раз начисляется **120 стартовых дайсов**. Остаток переносится между днями и столами. «Новый стол», перезагрузка, завершение или повторный вход не выдают запас повторно. Дневной запас не входит в заработок.

- **Roll:** обновляет все незакреплённые верхние пары. Без фиксаций стоит 6 дайсов.
- **Drop:** один FIFO-сдвиг нижнего ряда. Цена — `max(1, число нижних фиксаций)`. При трёх нижних фиксациях стоит ровно 3 дайса. Все шесть закреплены — сначала освободи одну.
- **Фиксация верха:** 1 / 3 Roll за 1 / 3 дайса. **Фиксация низа:** 3 / 6 Drop за 2 / 4 дайса. Срок расходуется только действиями своего ряда. Снять можно бесплатно, без возврата потраченного.
- **Доступно Roll:** целая часть `баланс / текущая цена Roll`. Это вычисляемое значение, а не остаток отдельного лимита.

Все цены фиксируются **до хода**, до истечения фиксаций. Автопоток делает такой же платный Drop раз в 5 секунд; ждёт в скрытой вкладке, модальном окне, при выборе фиксации и при отсутствии новых доступных наград. В журнале автоматические ходы помечены отдельно.

## Ardor, цена и награда

Пусть `L` — число всех фиксаций из 12, `S` — сила лучшей комбинации среди совпавших и закреплённых верхних фишек. Без неё `S = 0`, совпадение даёт 1, пара — 2, далее по рангу комбинации.

```text
точный Ardor = 100 × (12 − L) / (12 + S)
цена Roll = ceil(600 / точный Ardor)
награда комбинации = ceil(базовая награда × точный Ardor / 100)
```

Показанный индекс округляется до одного знака, расчёты используют неокруглённый. Больше фиксаций и сильнее удержанная комбинация → меньше Ardor → дороже Roll и меньше награды. Например, три нижние фиксации без удержанного верха: Ardor 75, Roll 8, Drop 3.

Ardor описывает открытость поля риску и масштаб выплат. **Точная вероятность** выбранной комбинации показывается отдельно; смена просматриваемой цели не меняет цену, награду или Ardor. Игрок видит цену неудачного хода и минимальную награду за выбранную цель при одной новой фишке. Выплата меньше цены хода означает чистый проигрыш.

## Совпадения и награды

Пары чисел между любыми верхней и нижней фишками совпадают в любом порядке. Каждая новая совпавшая верхняя фишка даёт награду за совпадение. Верхнее число и масть таких фишек образуют покерную комбинацию. Выплачивается **один старший бонус**, плюс награды за каждую новую фишку. Несколько нижних связей одной верхней фишки не умножают награду. Повторно оплаченная фишка не приносит дайсы, пока её не заменит новая.

Базовые награды при Ardor 100:

| Комбинация | Дайсов |
| --- | ---: |
| Совпадение | 3 за новую фишку |
| Пара | +8 |
| Две пары | +18 |
| Тройка | +30 |
| Стрит | +60 |
| Флеш | +90 |
| Фулл-хаус | +140 |
| Каре | +220 |
| Стрит-флеш | +400 |
| Роял-стрит | +650 |
| Пять одинаковых | +900 |
| Полный стрит | +1200 |
| Шесть одинаковых | +2000 |

Роял-стрит — костяная адаптация 2–3–4–5–6 одной масти; полный стрит — все числа 1–6. Таблица в игре показывает **текущие**, уже пересчитанные награды. Клик открывает легенду, формулу, шансы через Roll/Drop и число собранных комбинаций.

Вероятности используют точный расчёт по числам/мастям и полный перебор 36 исходов нового Drop. Тесты сравнивают модель с 20 736 исходами двух свободных верхних пар.

## Сохранение успехов и отчёты

Один атомарный JSON в LocalStorage **`dnr-save-v4`** содержит:

- постоянный кошелёк, суммы заработка/расходов и выдачи дневного запаса;
- дневные итоги и общую коллекцию: число оплаченных выигрышей каждого старшего класса;
- текущую сессию, фиксации, счётчики, до 500 последних событий и накопленную статистику без обрезки;
- до 20 сводок сессий и до трёх подробных архивов;
- статистику для каждой пары: сколько было проверок и сколько совпадений.

При обновлении импортируется коллекция из старых v3-сессий без повторного учёта одинаковых ID; старые ключи сохраняются. Настройки звука и автопотока используют `dnr-domino-sound-v3` / `dnr-domino-flow-v3`.

Успехи учитываются сразу после хода и не начисляются повторно при сохранении или восстановлении. «Забрать итог» показывает выиграно, потрачено, чистый результат, комбинации и пары с числом совпадений из всех проверок. Закрытие страницы сохраняет отчёт; **при следующем входе** он открывается автоматически. После закрытия браузера показать собственное окно уже невозможно. Время закрытой и скрытой страницы не считается активной игрой.

Проверка пары — ещё не оплаченная верхняя фишка после хода. Это наблюдения прошлого, а не прогноз следующего броска. Статистика доступна в игре и в JSON-экспорте. Данные не отправляются на сервер. Если хранилище недоступно, игра показывает это и продолжает работать в памяти.

## Версии и структура

- `node-js` — исходная JavaScript-версия.
- тег `vue-classic-v2` — старая классика/блиц.
- тег `domino-v3` — барабаны с предыдущей экономикой.
- `vue-js` — текущая игра; `gh-pages` — опубликованная сборка.

```text
src/game/engine.js                комбинации, вероятность, Ardor и цены
src/game/session.js               ходы, выплаты, фиксации и отчёт сессии
src/game/progress.js              кошелёк, дневной запас и коллекция
src/composables/useDiceGame.js     анимации, сохранение и жизненный цикл
src/App.vue                      стол, награды, легенды и отчёты
tests/                           математика, экономика, сохранения и Vue
```
