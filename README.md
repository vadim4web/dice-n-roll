# Dice’n’Roll

Игра с шестью костями: собирайте комбинации, сохраняйте очки или рискуйте следующим броском.

`npm start` — локальная игра на http://127.0.0.1:5173. `npm test` — проверка подсчёта комбинаций и вероятностей.

Классика: 10 раундов. Блиц: 90 секунд с первого броска, незабранные очки по окончании сгорают. Единица = 100, пятёрка = 50, тройка = число × 100 (три единицы = 1000). Следующая одинаковая кость удваивает тройку. Стрит 1–6 и три пары = 1500. Комбинации считаются внутри одного броска. Все шесть костей в комбинациях позволяют бросить все кости снова.

Пробел — бросок, Enter — забрать, 1–6 — выбор костей, M — звук. Рекорды и текущая игра хранятся локально в браузере. Звук по умолчанию выключен. Для шрифтов используется Google Fonts с системным запасным шрифтом.
