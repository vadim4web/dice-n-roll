# Dice’n’Roll · Vue

Аркада з шістьма кістками: збирайте комбінації, зберігайте очки або ризикуйте наступним кидком. Класика на 10 раундів і бліц на 90 секунд. Прогрес, звук і рекорди зберігаються в браузері.

## Гілки

- `node-js` — початкова версія на JavaScript із локальним Node.js-сервером.
- `vue-js` — ця версія: Vue 3, Composition API, SFC та Vite.
- `gh-pages` — готова статична збірка для GitHub Pages.

## Розробка

Потрібен Node.js 22.12 або новіший і npm.

```sh
git switch vue-js
npm ci
npm run dev
```

У Windows PowerShell із забороною `.ps1` використовуйте `npm.cmd` замість `npm`.

```sh
npm test             # правила, переходи гри та взаємодії Vue-компонентів
npm run build        # статична збірка у dist/
npm run verify:build # перевірка відносних шляхів та наявності ресурсів
npm run preview      # локальний перегляд production-збірки
```

## GitHub Pages

Гра працює за адресою <https://vadim4web.github.io/dice-n-roll/> після завершення публікації GitHub Pages.

```sh
git push origin vue-js
npm run deploy
```

`deploy` виконує production-збірку та публікує вміст `dist/` у гілку `gh-pages`. Потрібен доступ на push до `origin`. У налаштуваннях репозиторію **Settings → Pages** джерело має бути **Deploy from a branch → gh-pages → /(root)**.

Vite налаштований із `base: './'`: ресурси працюють як у підкаталозі `/dice-n-roll/`, так і на іншому статичному хостингу. `.nojekyll` вимикає обробку Jekyll. У production немає серверного коду, API, Vue Router або потреби в Node.js; на хостинг завантажується лише `dist/`. Google Fonts має системний запасний шрифт.

## Структура

```text
src/App.vue                    інтерфейс гри
src/components/                кості, піктограми та модальне вікно
src/composables/useDiceGame.js  реактивний стан, таймер, звук і збереження
src/game/session.js            незалежні від UI переходи гри
src/game/engine.js             комбінації та ймовірності
tests/                         тести правил, сесії й Vue-компонентів
```

## Правила

Одиниця = 100, п’ятірка = 50, три однакові = число × 100 (три одиниці = 1000). Кожна наступна однакова кістка подвоює вартість трійки. Стріт 1–6 і три пари = 1500. Комбінації рахуються в межах одного кидка. Якщо всі шість кісток дали очки, їх можна кинути знову. Порожній кидок забирає лише очки поточного раунду. У бліці час іде і з відкритими правилами; незбережені очки після завершення часу згорають.

Пробіл — кидок, Enter — забрати очки, 1–6 — вибір кісток, M — звук. Коли кнопка має клавіатурний фокус, Enter і пробіл активують її стандартним способом.
